# Караоке-клуб «Харизма»

Трёхстраничный frontend на HTML, CSS и JavaScript. React и серверная часть не используются. Интерфейс доступен на русском, английском, узбекском и венгерском языках; выбор языка сохраняется в браузере. Vite нужен только для локального запуска и сборки.

## Запуск

```bash
npm install
npm run dev
```

## Страницы

- `index.html` — главная
- `zaly.html` — залы и галерея
- `bronirovanie.html` — бронирование, FAQ и контакты

Общие стили находятся в `src/styles`, интерактивность и данные интерфейса — в `src/scripts/site.js`. Изображения Figma находятся в `public/assets`.

Для production-сборки выполните `npm run build`; готовые HTML-страницы появятся в `dist`.
